# ユーザー受入テスト（UAT）計画: コンビニPOSシステム MVP

## 1. ドキュメント概要

| 項目 | 内容 |
|------|------|
| バージョン | 1.0 |
| 作成日 | 2026-08-18 |
| 役割 | 開発チーム以外の関係者による最終受入テストの計画 |

## 2. UAT目的

- 開発チームが作成したシステムが、**業務要件を満たしていること**を確認する
- ユーザー視点での操作性・使いやすさを検証する
- step0200_spec.md の受け入れ基準（AC-1〜AC-13）が全て満たされることを確認する

## 3. UAT参加者

| 役割 | 担当 | 責務 |
|------|------|------|
| テスト実行者 | （未定） | テストシナリオの実行、結果記録 |
| 業務オーナー | （未定） | 業務観点での判定、妥当性確認 |
| 開発チーム | 開発者 | 問題発生時の支援、修正対応 |
| プロジェクトマネージャー | （未定） | UAT全体の進行管理、Go/No-Go判定 |

## 4. UAT環境

| 項目 | 詳細 |
|------|------|
| 実行環境 | Windows 10/11、.NET 8.0 Runtime |
| DB環境 | SQL Server LocalDB（テスト用データベース） |
| テストデータ | シードデータ5商品 + 追加テスト商品 |

## 6. UAT終了条件

| ID | 条件 |
|----|------|
| UC-1 | 全シナリオ（S-001〜S-010）がパスすること |
| UC-2 | 致命的な不具合（クラッシュ、データ損失）が0件であること |
| UC-3 | 業務オーナーが「受入可能」と判断すること |

## 7. 問題管理

| 問題深刻度 | 定義 | 対応方針 |
|-----------|------|----------|
| 致命的 | システムが起動しない、データが破損する | 修正完了までUAT停止 |
| 重大 | 主要機能が正常に動作しない | 修正後、該当シナリオを再実行 |
| 軽微 | 表示のズレ、 minor な操作感 | 記録のみ、修正はリリース後 |
