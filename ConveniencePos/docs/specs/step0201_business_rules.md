## 2. 商品管理ルール

### BR-001: 商品の識別
- 商品はJANコード（バーコード文字列）で唯一に識別する
- JANコードは13桁または8桁の数字文字列
- 同一JANコードが複数存在することはシステム上禁止

### BR-002: 商品の税率分類
- すべての商品は税率8%（軽減税率）または税率10%（標準税率）のいずれかに分類される
- 税率の判定基準（日本消費税法に基づく）:
  - **8%対象**: 飲食料品（お弁当、飲料、おにぎり等）
  - **10%対象**: 日用品、雑貨、紙類、タバコ等
- 商品マスタの税率フィールドで管理する

### BR-003: 商品価格
- 商品価格は税抜価格として管理する
- 税込価格は画面表示時に算出し、DBには保存しない

## 3. カート操作ルール

### BR-010: 商品追加
- バーコード入力時にDBから商品を検索する
- 該当商品が存在する場合:
  - カートに同じ商品がない場合: 数量1で新規追加
  - カートに同じ商品がある場合: 既存行の数量を+1
- 該当商品がない場合: エラーメッセージを表示し、カートは変更しない
- エラーメッセージ例: 商品が見つかりません (JAN: 入力値)

### BR-011: 数量制限
- 商品数量は正の整数のみ許容する（1以上）
- 数量が0以下に設定された場合の動作: **未定義（MVPでは対応不要）**
- 数量の最大値: **未定義（MVPでは制限なし）**

### BR-012: カート表示順序
- 商品追加順（FIFO: First In, First Out）で表示する
- 同一商品の数量増加時は、既存行の数量を更新し表示順は変更しない

### BR-013: カートクリア条件
- 以下のすべての条件を満たした場合にカートをクリアする:
  1. 「会計確定」ボタンが押された
  2. DB保存処理が成功した（DB保存完了）
- クリア対象: カート明細、預かり金額、お釣り表示

## 4. 金額計算ルール

### BR-020: 税込小計計算（商品単位）
- 税込小計 = Floor(単価 × 数量 × (1 + 税率/100))
- **端数処理: すべて切り捨て（Floor）**
- 計算順序: まず単価×数量、次に税率適用、最後にFloor

### BR-021: 税率別集計
- **8%対象額**: カート内すべての8%商品の 単価 × 数量 の合計
- **10%対象額**: カート内すべての10%商品の 単価 × 数量 の合計

### BR-022: 消費税額計算（税率別）
- 8%消費税額 = Floor(8%対象額 × 0.08)
- 10%消費税額 = Floor(10%対象額 × 0.10)
- **税率ごとに別々にFloor処理を行う**（合算してからFloorではない）

### BR-023: 合計金額
- 合計金額 = 税抜合計 + 8%消費税額 + 10%消費税額
- 税抜合計 = 8%対象額 + 10%対象額

### BR-024: お釣り計算
- お釣り = 預かり金額 - 合計金額
- 預かり金額 < 合計金額 の場合: お釣り = 0（負数にはしない）
- 預かり金額 = 0 の場合: お釣り = 0

### BR-025: 会計確定のブロック条件
- 預かり金額 < 合計金額 の場合、会計確定ボタンは無効化される
- 預かり金額 = 0 の場合も同様に無効化
- 預かり金額 = 0 でカートに商品がある場合も無効化

### BR-026: 計算例
```
【例1: 8%商品のみ】
おにぎり梅 ¥120 (8%) × 2個
税込小計 = Floor(120 × 2 × 1.08) = Floor(259.2) = 259
8%消費税額 = Floor(240 × 0.08) = Floor(19.2) = 19
合計金額 = 240 + 19 = 259

【例2: 10%商品のみ】
ポテトチップス ¥180 (10%) × 1個
税込小計 = Floor(180 × 1 × 1.10) = Floor(198) = 198
10%消費税額 = Floor(180 × 0.10) = Floor(18) = 18
合計金額 = 180 + 18 = 198

【例3: 混合税率】
おにぎり ¥120 (8%) × 1 + チップス ¥180 (10%) × 1
8%対象額  = 120
10%対象額 = 180
8%消費税額  = Floor(120 × 0.08) = Floor(9.6) = 9
10%消費税額 = Floor(180 × 0.10) = Floor(18.0) = 18
税抜合計    = 300
消費税額   = 9 + 18 = 27
合計金額 = 300 + 27 = 327
```

## 5. 取引確定ルール

### BR-030: 保存データ
- 会計確定時に以下のデータをDBに保存する:
  - **取引データ**: 作成日時、合計金額、消費税額
  - **取引明細**: 商品ID、数量、単価、適用税率（商品ごと）

### BR-031: 適用税率の記録
- 取引明細の適用税率には、購入時点のカート内商品の税率を記録する
- これは商品マスタの税率が将来変更されても、過去取引の税率を正確に保つため

### BR-032: 保存失敗時の動作
- DB保存処理が例外を発生した場合:
  - カートはクリアしない
  - エラーメッセージを表示する（MVPではコンソール出力）
  - ユーザーは再試行できる

## 6. レシート出力ルール

### BR-040: 出力条件
- DB保存処理が成功した直後にレシートを出力する
- ファイル名: receipt_[取引ID].txt
- 出力先: ユーザーのデスクトップ

### BR-041: レシートフォーマット
- 1行32文字の固定幅フォーマット
- 全角文字は2幅としてカウント
- 各行の右寄せには文字列の左寄せ機能を使用

### BR-042: レシート内容
- 店舗名: Convenience POS Store
- レジ番号: レジ#01
- 担当者名: 固定値（谷本 レジ担当）
- 取引番号: TRX-[取引ID]
- 日時: 年/月/日 時:分 形式
- 商品明細: [商品名] [数量]  ¥[税込小計] [税区分]
- 税内訳: 8%/10%それぞれの対象額と税額
- 合計・預かり金・お釣り

## 7. 例外・エラーハンドリング

### BR-050: エラー分類

| エラータイプ | 発生条件 | ユーザーへの表示 | システム動作 |
|-------------|----------|-----------------|-------------|
| 商品未発見 | JANコードがDBに存在しない | 商品が見つかりません | カート変更なし |
| DB接続エラー | DBに接続できない | （MVP: コンソールログ） | 画面操作継続可能 |
| DB保存エラー | DB保存処理が例外を発生 | （MVP: コンソールログ） | カート維持 |
| ファイル書き込みエラー | デスクトップへの書き込み権限なし | （MVP: コンソールログ） | 取引保存は完了済み |

## 8. 禁止事項

| ID | 禁止事項 | 理由 |
|----|----------|------|
| P-001 | 税率の合算後Floor処理 | 日本消費税法に違反（税率ごとの端数処理が義務） |
| P-002 | 負数の数量入力 | 業務上不正なデータ |
| P-003 | お釣りの負数表示 | ユーザー混乱の原因 |
| P-004 | DB接続文字列のハードコーディング | セキュリティリスク |
