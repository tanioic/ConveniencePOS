# 仕様拡張: 簡易レシートテキスト出力機能

## 1. 概要
「会計確定」ボタンを押してデータベースへの保存が成功した直後、提示されたレイアウトに基づいたレシートテキストを生成し、デスクトップ上に自動出力する。

## 2. 業務要件
- **出力タイミング**: 取引データのDB保存が成功した直後。
- **出力先**: 実行中ユーザーのデスクトップ。
- **ファイル名**: 取引IDを含むテキストファイル（例: 取引ID=1の場合、receipt_1.txt）。

### レシートレイアウト（1行32文字幅想定）
```
================================
Convenience POS Store
レジ#01  担当: 谷本 レジ担当

取引番号: TRX-[取引ID]
[現在の日時]

[商品名] [数量]  ¥[税込小計] [税区分]
税抜合計               ¥[税抜合計]
8% 対象: ¥[8%対象] 消費税: ¥[8%税]
10%対象: ¥[10%対象] 消費税: ¥[10%税]
消費税合計                 ¥[税合計]

税込合計              ¥[税込合計]
[現金] お預かり        ¥[預かり金]
お釣り                ¥[お釣り]
ありがとうお越し下さいました
```

## 3. 技術計画
- **アーキテクチャ方針**: ロジックは画面ロジック内、または専用のサービスに持たせる。
- **文字列操作**: 文字列操作機能を使用し、金額の右寄せや等幅の調整を行う。
- **ファイル書き込み**: ファイル書き込み機能を使用する。
