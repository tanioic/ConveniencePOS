# 仕様: コンビニPOSシステム MVP

## 1. バーコードスキャン機能
- ユーザーが手動入力（シミュレート）またはスキャナによるJANコード（バーコード）を読み取ると、DBから該当商品を検索する。
- 該当商品が存在する場合、既存の「取引明細（TransactionItems）」に数量1として追加する。
- 既に同じ商品がカートにある場合は、数量を+1する。
- 該当商品がない場合は、エラーメッセージを表示する。

## 2. 合計計算機能
- カート内容の変更をリアルタイムに感知し、「小計」「税率8%/10%対象額」「税額/内外判定」などを計算し結果に表示する。
- 預かり金額（現金・電子マネー）を入力すると、「お釣り」を即座に計算して表示する。
- 預かり金額が合計金額に満たない場合は、会計確定ボタンを無効にする。

## 3. 取引確定とDB保存機能
- 「会計確定」ボタンを押すと、取引データ（Transaction）と取引明細（TransactionItem）をSQL Serverに保存する。
- 保存後は、画面をリセットし、小計・税額・預かり金をクリアして次の取引を待つ。

## 4. 数量編集機能
- カート内の商品数量は、バーコードスキャン後にデフォルトで1が表示されるが、データグリッド上で直接編集して変更可能とする。
- 数量の変更はリアルタイムに合計金額・税額に反映される。
- **実装方式**: `CartItemViewModel` の `PropertyChanged` イベントを `MainViewModel` が購読し、`Quantity` 変更時に `RefreshTotals()` を呼び出して全合計プロパティの再計算・通知を行う。

## 5. 小計（税込）表示機能
- カート一覧の「小計」カラムには、税込金額（単価 × 数量 × (1 + 税率/100)、端数切り捨て）を表示する。
- レシート出力時も各商品の税込小計を表示する。
