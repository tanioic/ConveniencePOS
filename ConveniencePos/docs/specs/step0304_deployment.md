## 2. 動作環境要件

### 2.1. 必須環境

| 項目 | 要件 |
|------|------|
| OS | Windows 10 (1809以降) または Windows 11 |
| .NETランタイム | .NET 8.0 Desktop Runtime |
| データベース | SQL Server LocalDB (MSSQLLocalDB) または SQL Server Express |
| 画面解像度 | 1100x720 以上 |
| ディスク容量 | 100MB以上（DB含む） |

### 2.2. 推奨環境

| 項目 | 推奨値 |
|------|--------|
| CPU | Intel Core i3 以上 |
| メモリ | 4GB以上 |
| ディスク | SSD |

## 3. インストール手順

### 3.1. 事前準備
1. .NET 8.0 Desktop Runtime をインストール
2. SQL Server LocalDB をインストール（Visual Studioインストール時に選択可能）

### 3.2. アプリケーション配置
1. ビルド済みの `publish` フォルダをデスクトップにコピー
2. `ConveniencePos.exe` をダブルクリックで起動
3. 初回起動時にマイグレーションが自動実行される

### 3.3. 初期データ投入
- アプリケーション起動時にシードデータが自動投入される
- 対象商品: おにぎり梅、お茶、ポテトチップス、ティッシュ、ホットコーヒー

## 4. 日次運用フロー

### 4.1. 開店時
1. PCを起動
2. `ConveniencePos.exe` を起動
3. バーコード入力欄にフォーカスが来ることを確認
4. テスト商品（例: `4902370536317`）で動作確認

### 4.2. 営業中
- バーコードスキャン -> 商品追加 -> 預かり金額入力 -> 会計確定
- レシートはデスクトップに `receipt_[ID].txt` として保存される

### 4.3. 終店時
1. すべての取引がDBに保存されていることを確認
2. アプリケーションを閉じる
3. デスクトップのレシートファイルを必要に応じてバックアップ

## 5. 障害対応フロー

### 5.1. 障害分類と対応

| 障害レベル | 症状 | 対応 | 復旧時間目安 |
|-----------|------|------|-------------|
| Level 1 | アプリケーションが起動しない | .NET Runtime の再インストール | 30分 |
| Level 1 | DBに接続できない | LocalDB の再起動 (`sqllocaldb start MSSQLLocalDB`) | 10分 |
| Level 2 | 商品追加ができない | JANコードの確認、DB接続確認 | 5分 |
| Level 2 | 金額計算がおかしい | アプリケーション再起動 | 5分 |
| Level 3 | レシートが出力されない | デスクトップの書き込み権限確認 | 10分 |
| Level 3 | 画面がフリーズした | アプリケーションを強制終了して再起動 | 5分 |

### 5.2. ログ確認方法
- アプリケーションのエラーログはコンソール出力
- Visual Studio または `dotnet run` の出力ウィンドウで確認
- DBの障害ログは Windows イベントログを確認

## 6. データ管理

### 6.1. バックアップ
| 対象 | 方法 | 頻度 |
|------|------|------|
| データベース | `sqllocaldb` のファイルコピー | 日次 |
| レシートファイル | デスクトップフォルダのコピー | 日次 |

### 6.2. データベースファイルの場所
```
%USERPROFILE%\AppData\Local\Microsoft\Microsoft SQL Server Local DB\Instances\MSSQLLocalDB\
```

## 7. 制限事項（MVP）

| 項目 | 制限 | 将来対応 |
|------|------|----------|
| 同時接続 | 1ユーザーのみ | 複数レジ対応時に拡張 |
| データバックアップ | 手動 | 自動バックアップ機能 |
| 監視 | なし | ヘルスチェック機能 |
| アップデート | 手動配置 | 自動アップデート機能 |
