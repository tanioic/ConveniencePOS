# UI設計書: コンビニPOSシステム MVP

## 1. 画面構成
- 1画面で全機能を実装する
- キーボードイベントにより、バーコード入力欄でEnterキーを押すと商品登録を行う

## 3. バーコード入力エリア
- 白背景ボーダー (CornerRadius=8, Padding=16,12)
- 左端に📦アイコン (FontSize=28)
- 「バーコード」ラベル (FontSize=14, 色 #888)
- テキスト入力欄: FontSize=22、バーコード入力値に接続
- 「検索」ボタン: 緑背景 (#27AE60)、商品追加アクションに接続

## 4. カート一覧（DataGrid）
- 白背景ボーダー (CornerRadius=8)
- ヘッダ行: 暗色背景 (#34495E)、白文字
- 交互行背景: #FAFBFC

| カラム | 表示項目 | 幅 | 備考 |
|---|---|---|---|
| 商品名 | 商品名 | * (自動) | FontSize=15 |
| 税率 | 税率(%) | 60 | 8% or 10% を表示 |
| 数量 | 数量 | 80 | 編集可能 (TextBoxに切替) |
| 単価 | 単価(税抜) | 100 | ¥形式 右寄せ |
| 小計 | 税込小計 | 110 | ¥形式 太字右寄せ |

## 5. お会計パネル（右側）
- 白背景ボーダー (CornerRadius=8, Padding=20)
- 見出し: 「お会計」 FontSize=22 Bold 色 #2C3E50

### 表示項目（各 #F8F9FA 背景ボーダー、CornerRadius=6）
| 項目 | 表示内容 | フォーマット |
|---|---|---|
| 小計 | 税抜合計 | ¥形式 |
| 8%対象額 | 8%対象商品の合計 | ¥形式 |
| 消費税 (8%) | 8%消費税額 | ¥形式 |
| 10%対象額 | 10%対象商品の合計 | ¥形式 |
| 消費税 (10%) | 10%消費税額 | ¥形式 |

### 合計金額バナー
- 暗色背景 (#1A1A2E)、CornerRadius=6
- 左: 「合計」白色 FontSize=18 Bold
- 右: 合計金額 金色 (#F39C12) FontSize=28 Bold

### 預かり金額入力
- ラベル: 「預かり金額」 FontSize=14 色 #555
- テキスト入力欄: FontSize=20、預かり金額に接続

### お釣り表示
- 水色背景 (#EBF5FB)、CornerRadius=6
- 左: 「お釣り」 色 #2E86C1
- 右: お釣り金額 FontSize=26 Bold 色 #2E86C1

### 会計確定ボタン
- 会計確定アクションに接続
- 青背景 (#2E86C1)、白色文字、CornerRadius=6

## 6. キーボード操作
| キー | 場所 | アクション |
|---|---|---|
| Enter | バーコード入力欄 | 商品登録（商品追加アクション実行後、フォーカス再設定） |

- 起動時にバーコード入力欄にフォーカス

## 9. レシート出力
- テキストファイルとしてデスクトップに保存
- 幅32文字の固定幅フォーマット
- 全角文字は2幅としてカウント
- 内容: 店舗名、レジ番号、担当者、取引番号、日時、明細、税内訳、合計、預かり、お釣り
- 詳細は `step0207_extension_receipt_simple.md` を参照
