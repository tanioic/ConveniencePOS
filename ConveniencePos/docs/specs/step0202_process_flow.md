## 2. メインフロー（正常系）

```
[システム起動]
    |
    v
[バーコード入力待ち] <--------+
    | バーコード入力+Enter       |
    v                          |
[商品検索(DB)]                 |
    |                          |
  +-+--------+                 |
  |          |                 |
[商品あり]  [商品なし]          |
  |          |                 |
  v          v                 |
[カート追加/  [エラー表示]      |
 数量+1]       |                 |
  |          +---> 待機に戻る --+
  v
[合計金額再計算]
    |
    v
[預かり金額入力待ち]
    | 預かり金額入力
    v
[お釣り計算・表示]
    |
    v
[会計確定ボタン有効判定]
    |
  +-+--------+
  |          |
[有効]    [無効(預かり不足)]
  |          |
  v          v
[会計確定]   [ボタン押下不可]
  |
  v
[DB保存(Transaction+TransactionItem)]
    |
  +-+--------+
  |          |
[成功]    [失敗]
  |          |
  v          v
[レシート出力] [エラー表示+カート維持(再試行可)]
  |
  v
[カート・預かり金額クリア]
  |
  v
[バーコード入力欄にフォーカス復帰]
  |
  v
[次の取引待機]
```

## 3. 状態遷移図

```
  待機中(バーコード入力待ち)
    | バーコード入力
    v
  商品追加中(カートに商品あり)
    | 預かり金額入力
    v
  会計処理中(お釣り表示済み)
    | 会計確定ボタン押下
    v
  保存処理中(DB書き込み中)
    |
    +---> 正常完了(クリアして待機に戻る)
    +---> エラー(カート維持、再試行可能)
```

## 4. 例外フロー

### EF-001: 商品未発見
```
バーコード入力 -> 商品検索 -> 該当なし
  -> エラーメッセージ表示: "商品が見つかりません"
  -> バーコード入力欄をクリア
  -> フォーカスを再設定
  -> 待機中に戻る
```

### EF-002: DB保存失敗
```
会計確定 -> SaveChanges() 例外
  -> エラーログ出力(コンソール)
  -> カート・預かり金額を維持
  -> ユーザーは再試行可能
```

### EF-003: レシート出力失敗
```
DB保存成功 -> ファイル書き込み失敗
  -> 取引データは保存済み(取り消し不可)
  -> エラーログ出力
  -> カートはクリアし、次の取引に遷移
```

### EF-004: 預かり金額不足
```
預かり金額入力 -> ReceivedAmount < TotalAmount
  -> お釣り = 0 を表示
  -> 会計確定ボタンを無効化
  -> ユーザーは追加入力 or 金額修正が必要
```
