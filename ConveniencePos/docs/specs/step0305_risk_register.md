## 2. リスク評価基準

### 発生可能性

| レベル | 定義 |
|--------|------|
| 高 | 50%以上の確率で発生する |
| 中 | 25%〜50%の確率で発生する |
| 低 | 25%未満の確率で発生する |

### 影響度

| レベル | 定義 |
|--------|------|
| 高 | 納品遅延、データ損失、法的問題を引き起こす |
| 中 | 機能制限、品質低下を引き起こす |
| 低 | 軽微な不便さを引き起こす |
